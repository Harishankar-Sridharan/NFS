# Modifying a Planning Manually

### Add

#### Applying objects to the planning

In any display mode (day, week, or month), you can apply an object to the planning by selecting its type in the side menu and dragging and dropping it onto the planning. Where you drop it determines what it applies to:

* **Row header (a resource):** The object is applied to the selected resource for the whole duration currently displayed.
* **Column header (a period):** The object is applied to all displayed resources for the selected period.
* **A cell:** The object is applied to the selected resource for the selected period only

#### Confirming the action

After you drop an object onto the planning, you can:

* **Cancel** the action.
* **Configure** the action, notably its duration. This option is not available if you dropped the object onto a column header.
* **Validate** the action to confirm that the object has been applied to the planning.

> **Note:** If the object cannot be dropped at the location you have chosen, the information popup next to the mouse pointer stays greyed out, and the drop is not possible

### Deletion

#### Selecting and managing objects in the planning

You can select one or more objects in the planning by clicking a row header, a column header, or a cell. To select several objects, hold down the **CTRL** key while you click.

A summary of your selection appears in the bar at the bottom of the page. Click this link to manage the selected elements.

When objects are selected, new functions appear in the command bar:

* **Repeat the selection:** Configure the recurrence of the selected object(s).
* **Cancel the selection:** Deselect the selected object(s).
* **Delete the selection:** Drag and drop the selection onto the delete button \[icon]. A confirmation message appears.
