# One-off unavailabilities

## Overview

The one-off unavailabilities table on the [Unavailabilities](unavailabilities.md) page shows all upcoming one-off unavailabilities for the resource. A one-off unavailability applies to a specific period.

For each unavailability, the table displays:

* **Start date and time**
* **End date and time**
* **Unavailability type**

All future one-off unavailabilities are displayed.

## Sort the list

1. Click a column heading to sort the unavailabilities by that column.
2. Click the same heading again to reverse the sort order.

## Edit or delete an unavailability

* Click **Delete** to remove the unavailability. A warning message asks you to confirm the deletion before the unavailability is deleted.
* Click **Edit Notes** to view or modify the notes associated with the unavailability.

For each unavailability, you can add or modify a saved note.

To finish editing a note:

* Click **Save** to save the changes and return to the previous page.
* Click **Back** to return to the previous page without saving any changes.
