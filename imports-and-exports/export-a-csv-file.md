# Export a CSV file

This feature exports data for an item type. You choose the fields and file format.

## Access the feature

**Navigation:** `Administration > CSV Files > Export a CSV File`

## Use the feature

1. In **Entities to export**, select the **Entity**.
2. In **Fields (Ctrl+ for multiple selection)**, select the fields to export.
3. Use the arrows to add them to **Selected fields**.
4. In **CSV formatting**, check the file settings.
5. Select **Export**.

## Formatting settings

| Setting                           | Description                          |
| --------------------------------- | ------------------------------------ |
| **Field separator**               | Character separating columns         |
| **Text delimiter**                | Character surrounding text           |
| **Value list separator**          | Character separating multiple values |
| **Date format** / **Time format** | Format for dates and times           |
| **Additional field time format**  | Time format for additional fields    |
| **Format duration as a time**     | **True** or **False**                |
| **Charset**                       | File encoding                        |
| **Use header labels**             | **True** or **False**                |
| **Locale**                        | Regional setting                     |
