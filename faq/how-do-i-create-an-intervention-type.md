# How do I create an intervention type?

1. Go to **Administration > Company data > Intervention > Intervention type**, select the **Intervention group**, then select **Create an intervention type**.
2. Enter the **Name** and the **Average intervention duration** in `HH:mm`.
3. Complete the scheduling fields: **Default number of resources**, **Minimum number of resources**, and **Maximum number of resources** (1 to 9), **Priority**, **Favorite days**, and **Required skills**.
4. Select **Save**.

Intervention groups are created under **Intervention groups** with **Create an intervention group**.
