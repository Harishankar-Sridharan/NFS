# How do I create a form template?

1. Select the **Form template** tab, then select **New**.
2. Build the form in the editor, using the **Designer** tab and **Add Question**. The **Preview**, **Themes**, **Logic**, **JSON Editor**, and **Translations** tabs are also available.
3. Select **Save**, or **Cancel** to leave without saving.
