# How do I create a resource type or a job type?

1. Go to **Administration > Company data > Resource type** (or **Job type**), then select **Create a resource type** (or **Create a job type**).
2. On the **Information** tab, enter the **Name** and **Region**, which are required.
3. Select **Next page** to open the **Work week**, **Limits**, and **Priorities** tabs.
4. Select **Save**.

A job type also has a **Default location** field.
