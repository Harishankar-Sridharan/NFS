# How do I search for a customer?

1. Go to **Planning > Customers menu > Search for customers**, or use the **SEARCH FOR CUSTOMERS** shortcut.
2. Enter one or more criteria, such as **External reference**, **Company name**, or **Postal code**. Enable **More criteria** for additional fields.
3. Select **Search**.

The results table shows the **Company name**, **External reference**, **Work site**, **City**, **Address**, and **Postal code**.
