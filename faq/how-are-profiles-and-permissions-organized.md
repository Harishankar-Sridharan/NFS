# How are profiles and permissions organized?

Permissions work at three levels:

* An **access right** authorizes a specific action.
* A **permission collection** groups access rights by module.
* A **profile** combines one or more permission collections.

To create a profile, go to **Administration > Users > Profile**, enter its **Name**, select **Save**, then add collections on the **Collections** tab with **Add**. The profile is assigned to a user on the **User** tab of a human resource record.

{% hint style="info" %}
Test permission changes with a test account first.
{% endhint %}
