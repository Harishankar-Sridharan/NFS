# Which actions change an appointment's status?

* **Plan**: schedule the appointment as planned.
* **Book**: define the appointment time.
* **Accept**: its assignment must no longer change.
* **Confirm**: confirm the appointment.
* **Suspend**: call the customer back and reschedule in real time; no batch optimization applies.
* **Reactivate**: set it to Requested so batch optimization can schedule it.
* **Unplan**: return it to Requested or Suspended.
* **Replan**: reschedule by real-time optimization, or by setting a date and field worker.
* **Subcontract**: send it to the subcontractor.

The actions available depend on the appointment's current status.
