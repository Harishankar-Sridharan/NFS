# What is MySearch, and who can create views?

MySearch views are custom appointment lists. There are two kinds:

* **Administrator views** (the **General searches** tab, permission `1445`) are shared. There are 15 fixed slots, named MySearch 1 to 15. Users see a view only if they have the **Access to MySearch N appointment list** permission.
* **User views** (the **User** tab, permission `1446`) are personal. Use **Add search** to create one. The number of user views is not limited.

The **View managers** menu appears only with permission `1445` or `1446`.
