# How do I create a skill?

1. Go to **Administration > Company data > Skill**, then select **Create a skill**.
2. Enter **Name** and **Region**, then set the options:
   * **Required — In all cases, even if forced** means a task cannot be assigned to someone without the skill, even by forcing the assignment.
   * In a team, choose whether **at least one resource must have it** or **all must have it**.
3. Select **Save**.

Authorizations are created the same way, under **Administration > Company data > Authorization**. Skills are assigned in each human resource record.
