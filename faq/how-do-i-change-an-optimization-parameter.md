# How do I change an optimization parameter?

1. Go to **Administration > Optimization > Optimization parameters**.
2. Under **Select the parameter profiles to view/edit**, select the profile.
3. Open **Parameters shared by the various optimization modes**, **Parameters for real-time optimization**, or **Parameters for batch optimization**.
4. Edit the values, using the information icon on each row for help, and select **Save**.

{% hint style="warning" %}
These changes affect optimization results for every affected area. Have them validated and test them over a limited period first.
{% endhint %}
