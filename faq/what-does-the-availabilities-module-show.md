# What does the Availabilities module show?

The Availabilities module displays resource work schedules: day templates, breaks, and unavailabilities. Open it from **Application launcher > Availabilities**.

* You can view the day, the week, or the month. Each row is a resource.
* The grey bar shows the applied day template, such as **Standard work day**.
* The **Unavailability** legend distinguishes **Worked** and **Non-worked** types.
* Use the **⋮** icon beside a resource name to open **Weekly schedule** or **Resource mini card**.
