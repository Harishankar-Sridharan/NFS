# How do I export a CSV file?

1. Go to **Administration > CSV Files > Export a CSV File**.
2. In **Entities to export**, select the **Entity**.
3. In **Fields (Ctrl+ for multiple selection)**, select the fields, then use the arrows to add them to **Selected fields**.
4. In **CSV formatting**, check the **Field separator**, **Text delimiter**, **Value list separator**, date and time formats, **Charset**, **Use header labels**, and **Locale**.
5. Select **Export**.
