# How do I schedule a new appointment with optimization?

1. Open the customer record (for example, from **Planning > Customers menu > Search for customers**) and select **Create an appointment**. The customer must already exist.
2. On **Service type to perform**, select one or more service types and check the **Duration**.
3. Select **Optimized scheduling**.
4. On **Optimization settings**, select **Search**. On **Optimization results**, select a slot, then select **OK**.
5. Select **Schedule**, **Reserve**, **Accept**, **Confirm**, or **Confirm and send**, then select **OK**. The status becomes **Scheduled**.

If no slot suits, **Other actions** offers **Set status to Suspended**, **Set status to Requested**, **Subcontract**, and **Manual scheduling**.
