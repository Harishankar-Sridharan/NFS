# What are the Tools under Administration?

The **Tools** group holds maintenance functions: **Advanced tools**, **Recalculate distance**, **Check server status**, **Journals**, **JVM thread dump**, and **Mapping services**.

To recalculate distances, choose the scope (**Area**, **Worksite**, **Team**, or **Resources**), enter the period, and select **Recalculate**.

API documentation is under **Nomadia Field Service API**.

{% hint style="warning" %}
These tools affect the entire application. Restrict them to administrators and use them with Nomadia support.
{% endhint %}
