# How do I import a CSV file?

1. Go to **Administration > CSV Files > Import a CSV File**.
2. Check the file-reading settings (**Field separator**, **Text delimiter**, **Value list separator**, **Date format**, and **File encoding charset**) and the geocoding settings (**Geocoding tolerance** and **Minimum geocoding score**).
3. Choose the **Default work location**, then the **Import mode**: **Standard**, **Insert only**, or **Update only**.
4. Select the folder icon to choose the file, then select **Update**.

The **Stop** and **Previous result** buttons are next to **Update**.

{% hint style="warning" %}
An import changes application data. Check the file and the import mode before you select **Update**.
{% endhint %}
