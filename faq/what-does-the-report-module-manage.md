# What does the Report module manage?

Open the module from **Application launcher > Report**. It has two tabs:

* **Report template**: templates that generate appointment reports automatically as PDFs.
* **Form template**: forms that let technicians answer questions during an appointment.

Each list shows **Actions**, **Report title**, **Status**, **Creation date**, **Worksite**, **Intervention group**, and **Intervention type**.
