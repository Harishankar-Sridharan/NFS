# How do I change an application setting?

1. Go to **Administration > Customization > Application configuration**.
2. Enter part of the setting name in the filter field at the top of the tree.
3. Select the matching settings group and change the value in the right pane.
4. Select **Save**. The **Reset** button is next to **Save**.

The **Customization** group also has **Labels**, **Themes**, and **Colors** entries.

{% hint style="warning" %}
A changed setting affects the entire application. Change only settings whose effects you understand, and test the result.
{% endhint %}
