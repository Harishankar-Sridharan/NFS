# How do I configure an unavailability type?

1. Go to **Administration > Company data > Unavailability type**, then select **Create an unavailability type**.
2. Enter **Name** and **Region**.
3. Set the options, such as **Working time**, **Multi-resource**, **Default location**, and the **Default duration**, **Minimum duration**, and **Maximum duration** in **Minutes**, **Hours**, or **Days**.
4. Select **Save**.

Exceptional location types, under **Exceptional location type**, define hours and an address instead.
