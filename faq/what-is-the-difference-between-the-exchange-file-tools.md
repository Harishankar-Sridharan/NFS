# What is the difference between the exchange-file tools?

Under **Administration > CSV Files** you find **Semi-automatic import**, **Global CSV import/export**, **CSV import/export template**, **Circulation listeners**, and **Predefined export links**. **Specific Files** and **XML Files** hold file-based tools.

* **Semi-automatic import** guides you through steps with a progress bar. You can drop a file into **Drop file here**.
* **Global CSV import/export** imports with **Update** and exports with **Export**.
* The **CSV import/export template** page describes the exchange fields for each entity.

{% hint style="warning" %}
An import changes application data. Test with a small data set first.
{% endhint %}
