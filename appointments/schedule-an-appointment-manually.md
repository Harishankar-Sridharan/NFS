# Schedule an appointment manually

Manual scheduling lets you set an appointment’s field worker, date, and time yourself. The application then checks whether constraints are met.

## Access the feature

Manual scheduling is available:

* When scheduling an appointment, with **Manual scheduling**.
* From a scheduled appointment record, with **Manual rescheduling**.

## Use the feature

The **Manual scheduling** screen appears.

1. Check the **Optimization model** and the number of **Required field worker(s)**.
2. Under **Field worker**, select the field worker. The list is grouped by field-worker type.
3. Under **Date / Time**, enter the date and time.
4. Choose **exact** or **from**.
5. Select **Continue**.

![Manual scheduling screen](/broken/files/SaaM8hOWc5sGS9gQu82r)

## Result

The application checks the requested slot. If constraints are not met, messages appear at the top of the screen. For example:

* A proposed solution showing the date, time, field worker, and outward and return travel;
* **The selected slot is too early**, with the earliest available time;
* **The appointment completion window is not met.**

The **Force appointment** button then appears next to **Continue**.

![Validation messages after Continue, with the Force appointment button](/broken/files/nTcca3aH4bTnNee7pvDL)

## Points to note

* Read validation messages before using **Force appointment**.
* The **among several** checkbox and **Subcontract** button are also available on this screen.
* The arrow in the upper-left returns to the previous screen without scheduling.
