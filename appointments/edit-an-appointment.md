# Edit an appointment

The edit record lets you update appointment data, such as description, earliest and latest dates, contact details, priority, and additional fields.

## Access the feature

**Navigation:** `Appointment record > Edit...`

## Use the feature

1. Open the appointment record. For details, see [View an appointment record](view-an-appointment-record.md).
2. Select **Edit...**.
3. In the **Edit record**, update the required fields.
4. Select **Save**.

![Appointment edit record](/broken/files/IC0sFEo6l7VHS3xpyjgI)

The edit record includes **Description**, **Earliest date**, **Latest date**, **Customer name**, **Requester**, **Last name**, **First name**, **Home phone**, **Work phone**, **Mobile phone**, **Email**, **Fax**, **Priority**, **Required field worker(s)**, **Marked**, **With appointment**, **Urgent**, quantities, and miscellaneous fields.

## Result

The appointment record reopens with the updated data.
