# Disconnection

To log out of the application, click the ![Disconnect button](../.gitbook/assets/eteindre.png) button or close the browser window.

{% hint style="info" %}
**Disconnect from NFS**

Disconnecting from NFS ends your current user session but does **not stop processes that are already running**. Because NFS is hosted on a server, processes continue to run on the server even after the client session is disconnected.

In previous versions of NFS, additional options were available after you clicked the **Disconnect** button. The **Close window** option closed the browser window, and the **Login** option reopened the login page. These options may not be available in the current version.
{% endhint %}
