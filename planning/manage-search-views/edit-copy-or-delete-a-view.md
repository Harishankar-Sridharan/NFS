# Edit, copy, or delete a view

## Access the feature

**Navigation:** `Planning > Planning menu > View managers`

You can also select **Edit MySearch** from a view’s results list. This requires permission `1433`.

## Available actions

| Action        | Administrator view                                                                     | User view                                                                  |
| ------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Edit**      | Pencil icon in the **General searches** tab, or **Edit MySearch** on the results list. | Pencil icon in the **User** tab, or **Edit MySearch** on the results list. |
| **Copy**      | Not available.                                                                         | **Copy** creates a copy named “\<name> (2)”.                               |
| **Delete**    | Not available.                                                                         | **Delete** removes the view **immediately, without confirmation**.         |
| **Home page** | Select the checkbox, then select **Save changes** at the top of the page.              | Select the checkbox, then select **Save changes** at the top of the page.  |

![User tab with a view’s Edit, Copy, and Delete buttons](/broken/files/D1bbO1LFRCuUnrIBSglf)

## Edit a view

1. Select the view’s pencil icon, or select **Edit MySearch** from its results list.
2. The wizard opens with the view name in its title and the saved settings.
3. Update the required steps. When editing, **Save changes** is available on every step.
4. Select **Save changes**, then close the window.

![Wizard open for editing an existing view](/broken/files/dAF80cSUKjqRia2Lrhm9)

For details about each step, see [Configure a view with the wizard](configure-a-view-with-the-wizard.md).

## Points to note

* Deleting a user view does not require confirmation. If unsure, create a **copy** first.
* When editing a view for the first time, entering a **Tooltip** can clear the **Name** and **Counter name**. Check both before saving. This is a known issue.
* A newly created or renamed view may require a page **refresh** before it appears in the menu. This is a known issue.
* You cannot change view order in the menu. Administrator views follow their MySearch number. User views follow their creation order.
* A list’s CSV export uses the columns and order defined in the view.
