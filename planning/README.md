# Planning

## Overview

The Planning module is the NFS module designed for planning personnel, online advisors and personal assistants. Resources working in the field can also use it as a visualization tool. Use it to:

* take appointments manually or in an optimized form;
* modify, reschedule or cancel appointments;
* search for appointments using many different criteria;
* manage customer portfolios with an integrated CRM;
* monitor the consistency of plannings through lists of warnings and alerts;
* save visit reports for appointments, whether they are fulfilled or not;
* save resources' unavailabilities;
* consult plannings for the different structures within the organization;
* download and consult roadbooks;
* manage types of post;
* track vehicles in the field (tracking);
* locate customers, appointments and routes on the map.

## Resize the frames

The map, the planning and the information display frames can all be resized with the buttons at the top right of each frame ![Resize button](../.gitbook/assets/bouton-redimensionnement.png).

* ![Stretch the frame downwards button](../.gitbook/assets/bouton-etendre-le-cadre-vers-le-bas.png) stretches the frame downwards.
* ![Stretch the frame upwards button](../.gitbook/assets/bouton-etendre-le-cadre-vers-le-haut.png) stretches the frame upwards.
* ![Hide the frame button](../.gitbook/assets/bouton-masquer-le-cadre.png) hides the frame.
* ![Full screen button](../.gitbook/assets/bouton-plein-ecran.png) displays the frame in full screen mode.

You can also drag the sides of the frames with the mouse to resize them manually.

{% hint style="info" %}
The default size of the frames is defined and initialized by the resizing of the cartographic pane in the `Maptool.xml` file. If you resize the frames manually, their sizes are saved in a browser cookie.
{% endhint %}
