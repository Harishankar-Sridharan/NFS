# Strategic

**Opti-Time**'s Strategic module is accessible only when the [corresponding right](https://mynomadia.com/privatedoc/9LLcWh7j74sENa54/optitime-doc/docs/en/otgs-reference-book/utilisateurs.html#coll-droits) (Strategic tab > Perimeter > **STRATEGIC\_PLANNING\_GUEST** right) is associated to the user profile.

It is designed for use by managers. It enables them to measure, view, and optimise delivery of production and services (missions, interventions, deliveries) in line with customer constraints, and it can do this in the medium or long term.

Access this module by clicking in the [site header](https://mynomadia.com/privatedoc/9LLcWh7j74sENa54/optitime-doc/docs/en/otgs-reference-book/bandeau.html).\
From version 9.0 upwards, in addition to the currrent [area](https://mynomadia.com/privatedoc/9LLcWh7j74sENa54/optitime-doc/docs/en/otgs-reference-book/bandeau-changer-region.html) the user can create a [new study/simulation](https://mynomadia.com/privatedoc/9LLcWh7j74sENa54/optitime-doc/docs/en/otgs-reference-book/new_simul.html) from existing data in **Opti-Time**.
