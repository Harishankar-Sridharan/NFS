# Additional modules

Depending on your contract and your profile's rights, other modules are added to the main modules in the application launcher. A module appears only if your profile has the corresponding access right.

| Module                | Use it to                                                                          |
| --------------------- | ---------------------------------------------------------------------------------- |
| **Sectorization**     | Build and adjust customer sectorization projects on a map                          |
| **Fulfilment**        | Compare a field worker's planned day with the completed day                        |
| **Tracking**          | Track the position of resources equipped with a tracking device                    |
| **Report**            | Manage report and form templates                                                   |
| **Custom modules**    | Modules specific to your organization, whose name and content depend on the setup  |

## Access a module

**Navigation:** `Application launcher > module name`

## Sectorization

The Sectorization module lets you distribute customers into sectors and save these divisions as projects.

1. Open **Sectorization**. If the **Change region** window appears, choose the region, then select **OK**.
2. Define the scope of the sectorization: region, customer type, indicators, and data to display on the map.
3. In the sectorization project, create, edit, transfer, or delete sectors. Customers without a sector are flagged as unassigned.
4. Save the project, then validate it to apply it.

## Fulfilment

The Fulfilment module compares a field worker's planned day with the completed day. For more information, see [Fulfilment](../fulfilment/fulfilment.md).

## Tracking

The Tracking module displays the positions of mobile resources equipped with a tracking device, and their waypoints: departure, arrival, visits.

{% hint style="info" %}
The Tracking module requires a tracking service configured for your environment. The tracking interface (filters, map) is provided by that service.
{% endhint %}

To view the last position of vehicles from the Planning module, see [Use the location and export tools](../planning/use-location-and-export-tools.md).

## Report

The Report module lets you create form templates and generate intervention reports. For more information, see [Report module overview](../report/report-overview.md).

## Custom modules

Your organization can have custom modules, for example a page of useful links. Their name in the application launcher and their content depend on your environment's setup. For any question, contact your administrator.
