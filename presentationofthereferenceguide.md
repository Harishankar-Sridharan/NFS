#### Glossary

A **Glossary** is provided at the end of this guide. It defines the key terms and concepts used throughout the documentation.

#### NFS Documentation

This User Guide is part of the **NFS documentation set**, which provides information about installing, using, and integrating the application.

The NFS documentation consists of three main guides:

* **Installation Guide:** Describes the NFS architecture and provides manual and automated installation procedures.
* **User Guide:** Provides detailed information about the application's features and functions, organised according to the NFS menu structure.
* **Integration Guide:** Describes data integration and the integration of NFS components with third-party applications.

#### Documentation Conventions

This User Guide describes the features and functions available through the different **NFS** menus. Each topic explains how to use a specific feature or perform a particular task.

Throughout the guide, **highlighted sections** are used to provide additional information, clarify concepts, or draw attention to important points.
