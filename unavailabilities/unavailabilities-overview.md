# Unavailabilities overview

An unavailability is a period during which a resource cannot receive appointments, such as leave, a meeting, or a medical appointment. Unavailabilities appear in resource schedules.

## In this section

* [Create an unavailability](create-an-unavailability.md)
* [Search for unavailabilities](search-for-unavailabilities.md)

You can also add an unavailability from the **Availabilities** module. For more information, see Availabilities.
