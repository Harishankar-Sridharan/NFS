# Search for unavailabilities

Unavailability search finds declared unavailabilities by resource, type, status, or period.

## Access the feature

**Navigation:** `Planning > Planning menu > Search for unavailabilities`

## Use the feature

1. Enter the required criteria: **Unavailability ID**, **External reference**, **Address**, **Postal code**, **City**, **Country**, **Team**, **Resource**, **Group**, **Type**, and **Status**.
2. Enter the **From** and **To** dates in **Date**.
3. Select **Search**.

## Result

The **Unavailability management** page shows the number of unavailabilities found. The table displays the **External reference**, **Type**, **Resource**, **Status**, **City**, the person who entered the unavailability (**Entered by**), **Date / Time**, and **Duration**.

## Notes

* The **Change statuses** button is available below the results table.
* The **Reset** button is available next to **Search**.
