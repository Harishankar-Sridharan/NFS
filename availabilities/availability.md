# Availabilities

The Availabilities module displays resource work schedules: day templates, breaks, and unavailabilities. You can also add an unavailability directly from the schedule.

## Access the module

**Navigation:** `Application launcher > Availabilities`

## Identify screen areas

### Top bar

| Element                            | Purpose                                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------------------------- |
| Arrows around the date             | **Go to the previous period** / **Go to the next period**                                 |
| Calendar icon                      | **Configure the range**                                                                   |
| Arrows                             | **Return to the previous schedule** / **Restore the next schedule**                       |
| List icon                          | **Display the appointment list**                                                          |
| Scope, such as a work site         | **Select the display scope**                                                              |
| **Search** field and related icons | **Open the settings panel**, **Enable the filter**, **Open the resource selection panel** |
| Icons on the right                 | **Export the schedule**, **Print the schedule**, **Navigate between services**            |

### Left panel

* The icons at the top let you **Go to today's date** and select a view: **View the day schedule**, **View the weekly schedule**, or **View the monthly schedule**.
* The monthly calendar lets you select a date.
* The **Unavailability** legend distinguishes **Worked** and **Non-worked** types.
* The **Milestone**, **Week template**, and **Day template** sections are collapsible.

### Schedule

Each row represents a resource. The grey bar displays the applied day template, such as **Standard work day**. The cutlery icon indicates the lunch break.

## Use a resource menu

Select the **⋮** icon to the right of a resource name. The menu provides **Weekly schedule** and **Resource mini card**.

## Add an unavailability from the schedule

1. Hover over a resource time slot. A window displays the **Available working hours** and day template.
2. Select the **Add an unavailability** icon.
3. In the creation window, enter the **Type**, **Duration**, and dates. The resource is prefilled.
4. Confirm with **OK**. Select **Cancel** to close the window without creating an unavailability.

The fields in this window are the same as in [unavailability management](../unavailabilities/create-an-unavailability.md).

## Notes

* The hover window also provides the **Add a position** icon.
