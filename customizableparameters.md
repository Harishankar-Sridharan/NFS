#### (fr) APPOINTMENT

(fr) appointment.list.myAction1: Custom for myAction 1 button below the appointment lists (fr) destination : where the action is displayed\
default value : popup

(fr) destinationCaption : (optional) a label for the destination-header (titles popup and frame-wrapper, see _useInternationalization_)\
default value : non renseigné

(fr) destinationHeight : (optional) the destination dimensions height, in pixels. Default = 0 (means _auto_)\
default value : 0

(fr) destinationWidth : (optional) the destination dimensions width, in pixels. Default = 0 (means _auto_)\
default value : 0

(fr) HTTPAdditionalParameters : (optional) any other information to send to destination, as HTTP parameters. Item format: param\_name=param\_value. Items are comma-separated. The escape character is backslash\
default value : non renseigné

(fr) HTTPListFields : (optional) the business model pieces of data to send to destination, as HTTP parameters (see the _exchange model_ part of the app API documentation). Items are comma-separated\
default value : non renseigné

(fr) HTTPMethod : the HTTP method in use to load the destination contents\
default value : get

(fr) HTTPParametersFormat : (optional) the format of the HTTP parameters sent to destination. Default = (empty) (means _standard HTTP_)\
default value : non renseigné

(fr) icon : non renseigné\
default value : non renseigné

(fr) label : a label for the trigger-button (see _useInternationalization_)\
default value : non renseigné

(fr) onCloseEvent : (optional) what happens once the action is terminated (incompatible with _destination=currentFrame|newWindow|callcenterLeftMenu_)\
default value : nothing

(fr) style : (optional) CSS classes names (whitespace-delimited)\
default value : non renseigné

(fr) tooltip : a label for the trigger-button tooltip (see _useInternationalization_)\
default value : non renseigné

(fr) trigger : how is triggered: on mouse click, or mouse hover (_hover_ is incompatible with _destination=newWindow_)\
default value : click

(fr) URL : relative or absolute URL\
default value : non renseigné

(fr) useInternationalization : a static (false) or dynamic (true, auto-referencing the language-file) strategy for labels. When using the dynamic strategy, any label-setting value is ignored\
default value : true
