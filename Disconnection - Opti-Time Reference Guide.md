### Disconnection

To log out of the application, the user can click on the ![images/ref/buttons/eteindre.png](./images/eteindre.png) button or close the internet browser window.

|  |  |
| --- | --- |
| [Note] | Note |
| Disconnecting from the application does not mean **Stop any processes currently running**. The application is hosted on a server that continues to function even when the client session has stopped.  In earlier versions, having first clicked on the images/ref/buttons/eteindre.png button, another button Close window served to close the browser window and another button Login allowed you to display again the [Login](https://mynomadia.com/privatedoc/9LLcWh7j74sENa54/optitime-doc/docs/en/otgs-reference-book/otgs-connexion.html "Running the application") window. |
