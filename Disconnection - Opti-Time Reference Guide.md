# Disconnection

To log out of the application, the user can click on the ![images/ref/buttons/eteindre.png](.gitbook/assets/eteindre.png) button or close the internet browser window.

| <p></p><h4>Disconnect from NFS</h4><p>Disconnecting from <strong>NFS</strong> ends your current user session but does <strong>not stop processes that are already running</strong>. Because NFS is hosted on a server, processes continue to run on the server even after the client session is disconnected.</p><blockquote><p><strong>Note:</strong> In previous versions of NFS, additional options were available after clicking the <strong>Disconnect</strong> button. The <strong>Close window</strong> option closed the browser window, while the <strong>Login</strong> option reopened the login page. These options may not be available in the current version.</p></blockquote> |      |
