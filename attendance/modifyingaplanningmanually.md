# Modifying a Planning Manually

## Add objects to the planning

In any display mode (day, week or month), you can apply an object to the planning. Select its type in the side menu and drag and drop it onto the planning. Where you drop it determines what it applies to:

* **Row header (a resource):** The object is applied to the selected resource for the whole duration currently displayed.
* **Column header (a period):** The object is applied to all displayed resources for the selected period.
* **A cell:** The object is applied to the selected resource for the selected period only.

{% hint style="info" %}
You can display additional information on the template types ([day](../administration/companydata.md), [week](../administration/companydata.md), [on-call duty day template](../administration/companydata.md) and [on-call duty week template](../administration/companydata.md)) by clicking the ![Information button](../.gitbook/assets/bouton-informations.png) button. The infobox summarizes the times associated with each of these templates, along with the area or worksite of affiliation.
{% endhint %}

### Confirm the action

After you drop an object onto the planning, you can:

* **Cancel** the action.
* **Configure** the action, notably its duration. This option is not available if you dropped the object onto a column header.
* **Validate** the action to confirm that the object has been applied to the planning.

{% hint style="info" %}
If the object cannot be dropped at the location you have chosen, the information popup next to the mouse pointer stays grayed out, and the drop is not possible.
{% endhint %}

## Delete objects from the planning

### Select and manage objects in the planning

You can select one or more objects in the planning by clicking a row header, a column header or a cell. To select several objects, hold down the **Ctrl** key while you click.

A summary of your selection appears in the bar at the bottom of the page. Click this link to manage the selected elements.

When objects are selected, new functions appear in the command bar:

* **Repeat the selection:** Configure the recurrence of the selected objects.
* **Cancel the selection:** Deselect the selected objects.
* **Delete the selection:** Drag and drop the selection onto the delete button \[icon]. A confirmation message appears.
