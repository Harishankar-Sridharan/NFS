# Glossary

Find the meaning of the terms that the application and this guide use.

## Terms

The terms are in alphabetical order. Each definition has a link to the topic that explains it in detail.

| Term | Meaning |
| ---- | ------- |
| **Accept** | An action that sets an appointment so that its assignment must no longer change. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Access right** | An access right authorizes a specific action. Access rights are grouped in permission collections. See [Manage profiles and permissions](../administration/manage-profiles-and-permissions.md). |
| **Administrator view** | A MySearch view that is shared with several users. There are 15 fixed slots, named MySearch 1 to 15. See [Create an administrator view](../planning/manage-search-views/create-an-administrator-view.md). |
| **Application configuration** | The tree of settings under Administration > Customization. You filter it by name, change a value and save it. See [Customize the application](../administration/customize-the-application.md). |
| **Application launcher** | The icon at the top left of the screen that opens the modules. See [Navigate the application](../introduction/navigate-the-application.md). |
| **Appointment** | A visit to a customer that you schedule and assign to a field worker. It has a status. The mobile app calls it an intervention. See [Appointments overview](../appointments/appointments-overview.md). |
| **Appointment record** | The page that shows the information of an appointment, in the sections General, Customer, Communication, Completion status, Additional data, Comments, Messages and History. See [View an appointment record](../appointments/view-an-appointment-record.md). |
| **Appointment status** | The state of an appointment, for example Requested, Planned, Confirmed or Completed. Statuses are grouped in families. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Attendance** | On the Portal, the daily number of field workers who are present, partially absent or absent. See [Portal](../portal/portal.md). |
| **Authorization** | A requirement for performing interventions, created in the same way as a skill. See [Manage skills and authorizations](../administration/manage-skills-and-authorizations.md). |
| **Availability** | The work schedule of a resource: its day templates, its breaks and its unavailabilities. See [Availabilities](../availabilities/availability.md). |
| **Book** | An action that defines the time of an appointment. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Calendar type** | The kind of schedule that the Planning module displays: Interventions, Workload, Position or Intervention type. See [View the schedule](../planning/view-the-schedule.md). |
| **Candidate** | A family of appointment statuses that contains Requested and Suspended. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Confirm** | An action that confirms an appointment. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Customer** | The record of a company that you serve. You use it to schedule and review appointments. See [Customers overview](../customers/customers-overview.md). |
| **Dashboard** | A set of supervision tables and analyses that you configure with criteria such as human resources, period and activities. The Portal is the home dashboard. See [Configure and view dashboards](../supervision/configure-and-view-dashboards.md). |
| **Day template** | The working hours of a day, with a lunch break and a break duration. You create day templates before week templates. See [Manage calendars](../administration/manage-calendars.md). |
| **Domain** | A group of regions. See [Manage geographic organization](../administration/manage-geographic-organization.md). |
| **Equipment** | An item that the company manages, like a subcontractor or a product. A product record uses the equipment fields. See [Manage subcontractors, equipment and products](../administration/manage-subcontractors-equipment-and-products.md). |
| **Exceptional location** | A location that replaces the usual one. Its type defines the hours and the address. See [Configure unavailability and exceptional location types](../administration/configure-unavailability-and-exceptional-location-types.md). |
| **Exchange files** | The tools that import and export data in files: CSV files, specific files and XML files. See [Manage exchange files](../administration/manage-exchange-files.md). |
| **Field worker** | A person who carries out appointments in the field. You see their schedule, their route indicators and their workload. See [View the schedule](../planning/view-the-schedule.md). |
| **Forecast workload** | On the Portal, a weekly bar chart for the next 3 weeks that compares the hourly capacity with the forecast workload. See [Portal](../portal/portal.md). |
| **Form template** | A form that lets technicians answer questions during an appointment. See [Report module overview](../report/report-overview.md). |
| **Fulfilment** | The comparison of the planned day of a resource with its completed day. See [Fulfilment](../fulfilment/fulfilment.md). |
| **Geocoding** | Finding the location of an address on the map. When you create a customer, you validate the address and choose the matching one. See [Create a customer](../customers/create-a-customer.md). |
| **Human resource** | The record of a resource, with tabs such as Information, Assignment, User, Typical week, Limits and Skills. See [Manage human resources](../administration/manage-human-resources.md). |
| **Import mode** | The way that a CSV import treats existing data: Standard, Insert only or Update only. See [Import a CSV file](../imports-and-exports/import-a-csv-file.md). |
| **Intervention group** | A group of intervention types. See [Configure interventions](../administration/configure-interventions.md). |
| **Intervention type** | The kind of work of an appointment, with an average duration, a number of resources, a priority, favorite days and required skills. See [Configure interventions](../administration/configure-interventions.md). |
| **Job type** | A type of job that is used for human resources. It has a default location. See [Manage resource and job types](../administration/manage-resource-and-job-types.md). |
| **Log** | The history of the actions performed on appointments, unavailabilities and exceptional locations. See [View the log](../supervision/view-the-log.md). |
| **Manual scheduling** | Scheduling an appointment by choosing the field worker and the date and time yourself, without the optimizer. See [Schedule an appointment manually](../appointments/schedule-an-appointment-manually.md). |
| **Mini-card** | The card of a resource, with the tabs ROUTES, QUOTA and VEHICLE. See [Display route indicators in the resource mini-card](../planning/resource-monitoring/display-route-indicators-in-the-resource-mini-card.md). |
| **Module** | A main part of the application that you open from the application launcher, such as Portal, Planning, Supervision or Administration. See [Overview](../introduction/overview.md). |
| **MySearch** | A custom appointment list. There are administrator views and user views. See [Manage search views](../planning/manage-search-views/README.md). |
| **Objective** | A target value for a human resource, a work site or a resource type over a period. See [Manage objectives, activity monitoring, and typologies](../administration/manage-objectives-activity-monitoring-and-typologies.md). |
| **On-call duty** | A duty that is organized with on-call day templates and week templates. See [Configure on-call duties](../administration/configure-on-call-duties.md). |
| **On-call sector** | A sector that divides the on-call activity. See [Manage geographic organization](../administration/manage-geographic-organization.md). |
| **Optimization profile** | A profile of optimization parameters that you view and edit. See [Configure optimization](../administration/configure-optimization.md). |
| **Optimized scheduling** | Scheduling an appointment by searching for a slot with the optimizer, then selecting a result. See [Schedule an appointment](../appointments/schedule-an-appointment.md). |
| **Permission collection** | A group of access rights by module. See [Manage profiles and permissions](../administration/manage-profiles-and-permissions.md). |
| **Plan** | An action that schedules an appointment as planned. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Portal** | The home dashboard: attendance, daily activity and forecast workload. See [Portal](../portal/portal.md). |
| **Product** | An item with a family and a unit price. You create the product family first. See [Manage subcontractors, equipment and products](../administration/manage-subcontractors-equipment-and-products.md). |
| **Product family** | A family of products. You create it before the products. See [Manage subcontractors, equipment and products](../administration/manage-subcontractors-equipment-and-products.md). |
| **Profile** | A combination of permission collections. You assign it to a user in the human resource record. See [Manage profiles and permissions](../administration/manage-profiles-and-permissions.md). |
| **Reactivate** | An action that sets an appointment to Requested, so that batch optimization can schedule it. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Region** | The assignment area for resources, teams and configuration data. See [Manage geographic organization](../administration/manage-geographic-organization.md). |
| **Report template** | A Word template that generates PDF appointment reports automatically. See [Generate appointment reports](../report/generate-appointment-reports.md) and [Prepare a report Word template](../report/prepare-a-report-word-template.md). |
| **Resource type** | A type of resource that is used for human resources. See [Manage resource and job types](../administration/manage-resource-and-job-types.md). |
| **Sector** | A division of the activity, for example by city. See [Manage geographic organization](../administration/manage-geographic-organization.md). |
| **Sectorization** | The module for defining the sectorization scope. See [Overview](../introduction/overview.md). |
| **Single sign-on** | If your organization uses it, you select Sign in with SAML to sign in. See [Sign in](../introduction/sign-in.md). |
| **Skill** | A requirement for performing interventions. A skill can be required in all cases, even if the assignment is forced. See [Manage skills and authorizations](../administration/manage-skills-and-authorizations.md). |
| **Status family** | A group of appointment statuses: Candidate, Scheduled, Completed, Cancelled and Subcontracted. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Subcontractor** | A company that you manage in the Administration module, and to which an appointment can be subcontracted. See [Manage subcontractors, equipment and products](../administration/manage-subcontractors-equipment-and-products.md). |
| **Supervision** | The module for monitoring appointments, the log, dashboards and analyses. See [Supervision overview](../supervision/supervision-overview.md). |
| **Suspend** | An action to call the customer back and reschedule in real time. No batch optimization applies. See [Understand appointment statuses](../introduction/appointment-statuses.md). |
| **Team** | A group of field workers, with a name, a service region and members. See [Manage teams](../administration/manage-teams.md). |
| **Tracking** | The module for monitoring location equipment. See [Overview](../introduction/overview.md). |
| **Unavailability** | A period when a resource is not available. You can declare a one-off or a repeating unavailability, and search for unavailabilities. See [Unavailabilities overview](../unavailabilities/unavailabilities-overview.md). |
| **Unavailability type** | The configuration of an unavailability: name, region, working time, multi-resource, default location and duration limits. See [Configure unavailability and exceptional location types](../administration/configure-unavailability-and-exceptional-location-types.md). |
| **User view** | A personal MySearch view that only you can see. The number of user views is not limited. See [Create a user view](../planning/manage-search-views/create-a-user-view.md). |
| **Week template** | A template that selects a day template for each day of the week. See [Manage calendars](../administration/manage-calendars.md). |
| **Work site** | A workplace that is shared by several resources, such as an agency, a depot or a store. See [Manage geographic organization](../administration/manage-geographic-organization.md). |
