# View the log

The log lists actions performed on data, such as creation, status changes, and confirmation. It identifies who performed each action and when.

## Access the feature

**Navigation:** `Supervision > Log`

## Use the feature

The **Log configuration** page appears.

1. In **Select a business data type**, choose **All**, **Appointments**, **Unavailabilities**, or **Exceptional locations**.
2. In **Resource**, choose the **Entering resource** or **Performing resource** if needed. Then choose the scope: **a person**, **a team**, **a work site**, or **By region**.
3. Complete optional fields if needed:
   * **Enter a customer**: **Customer name**, **Contact name**, **Reference**;
   * **Enter an identifier**: **External**, **Internal**;
   * **Select a period**: **From** and **To**.
4. To limit results, enable **Limit display to** and choose the number of **last actions**.
5. Select **Validate**.

![Log configuration page](/broken/files/VUe5I7Zk2cSRl9mkjFdS)

## Result

The **Search result** page displays the data **Type**, **Identifier**, **Modification date and time**, **Author**, and completed **Action** for each entry.

![Log search result](/broken/files/PcyQf3kExdjnIpFTOl2w)

The **Back** button is available below the table.
