# Supervision overview

The Supervision module brings together activity monitoring tools: dashboards, past and upcoming appointment tracking, action logs, and analyses.

## Access the module

**Navigation:** `Application launcher > Supervision`

The left menu provides these entries:

| Entry               | Content                                                                                                                                                                                                                                                  |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dashboard**       | Graphical activity dashboard                                                                                                                                                                                                                             |
| **Supervisor home** | Track past and upcoming appointments                                                                                                                                                                                                                     |
| **Log**             | History of actions on appointments and unavailabilities                                                                                                                                                                                                  |
| **Dashboard** group | **Configure**, **Appointments**, **Schedule summary by day**, **Schedule summary by week**, **Edit dashboard**                                                                                                                                           |
| Analyses            | **Availabilities**, **Appointment scheduling quantity**, **Appointment scheduling quality**, **Objectives**, **Customer distance matrix**, **Customer centers of gravity**, **Overall unavailability schedule**, **Scheduling compliance**, **Overtime** |

## Dashboard

When you open the module, the dashboard displays indicators for total, completed, scheduled, and requested appointments, charts, and a detailed table. The displayed period appears at the top right.
