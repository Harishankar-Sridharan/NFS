# Presentation of the Reference Guide

## Overview

This guide provides an overview of the NFS application and its features. It helps you understand the overall application workflow and gives detailed information about specific functions.

The guide is organized into **nine sections**, following the structure of the **NFS application menu**. Each section covers the features and functions available in the corresponding menu area.

* [Portal](../portal/README.md)
* [Planning](../planning/README.md)
* [Supervisor](../planning-1/README.md)
* [Attendance](../attendance/README.md)
* Strategic
* [Sectorization](../sectorization.md)
* [Fulfilment](../fulfilment.md)
* [Tracking](../tracking.md)
* [Administration](../administration/README.md)

## Glossary

A **Glossary** is provided at the end of this guide. It defines the key terms and concepts used throughout the documentation.

## NFS documentation

This User Guide is part of the NFS documentation set, which provides information about installing, using and integrating the application.

The NFS documentation consists of three main guides:

* **Installation Guide:** Describes the NFS architecture and provides manual and automated installation procedures.
* **User Guide:** Provides detailed information about the application's features and functions, organized according to the NFS menu structure.
* **Integration Guide:** Describes data integration and the integration of NFS components with third-party applications.

## Documentation conventions

This User Guide describes the features and functions available through the different NFS menus. Each topic explains how to use a specific feature or perform a particular task.

Throughout the guide, highlighted sections provide additional information, clarify concepts or draw attention to important points.

{% hint style="warning" %}
The functions and screens presented in the current chapter are configurable and can vary significantly from one configuration to another. See the chapters [Customization](../administration/customization.md) and [User Handling](../administration/userhandling.md). The information in this documentation is therefore subject to the parameters and settings that you define.
{% endhint %}
