# Overview

Nomadia Field Service is a web application. Access it from a browser, using the address and credentials provided by your administrator.

## Application modules

The application launcher, at the top left of the screen, provides access to the following modules:

| Module             | Main use                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **Portal**         | Home dashboard: today's attendance, daily activity, and forecast workload                |
| **Planning**       | Booking appointments, searching, field-worker schedules, customers, and unavailabilities |
| **Supervision**    | Monitoring appointments, action log, dashboards, and analysis                            |
| **Availabilities** | Field-worker availability calendar and unavailability declarations                       |
| **Sectorization**  | Defining the sectorization scope                                                         |
| **Fulfilment**     | Comparing a field worker's planned day with their completed day                          |
| **Tracking**       | Monitoring location equipment                                                            |
| **Report**         | Report and form templates                                                                |
| **Administration** | Company data, users, configuration, and files                                            |

{% hint style="info" %}
The displayed module list depends on your profile and environment configuration.
{% endhint %}
