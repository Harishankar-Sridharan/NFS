# Quick start

Follow the main planning tasks from sign-in to a scheduled appointment, with a link to the full topic for each step.

## Overview

This page is a short path through Nomadia Field Service for a planner. Each step is one task, and it links to the topic that explains it in detail. Your profile can hide some modules, menus and actions, so you may not see every step.

## Before you begin

* You have the address of the application and the credentials that your administrator provided.
* Your administrator has set up the field workers and the reference data, such as intervention types.

## Your first appointment

1. **Sign in.** Open the address in your browser, enter your username and password, and select **Sign in**. If your organization uses single sign-on, select **Sign in with SAML**. See [Sign in](sign-in.md).
2. **Check the Portal.** The Portal is the home dashboard. It shows the attendance, the daily activity and the forecast workload. See [Portal](../portal/portal.md).
3. **Open Planning.** Select the application launcher at the top left of the screen, then select **Planning**. See [Navigate the application](navigate-the-application.md) and [Planning overview](../planning/planning-overview.md).
4. **Create the customer.** Go to **Planning > Customers menu > Create a customer**. Enter the **Company name** and the address, select **Validate address**, then select **Save**. See [Create a customer](../customers/create-a-customer.md).
5. **Schedule the appointment.** On the customer record, select **Create an appointment**, choose the service types, and select **Optimized scheduling**. Search for a slot, select a result, then schedule the appointment. See [Schedule an appointment](../appointments/schedule-an-appointment.md).
6. **Follow it in the schedule.** In the schedule, choose the calendar type, the period and the level, then select the item to display on the right. See [View the schedule](../planning/view-the-schedule.md).
7. **Change its status.** Hover over the appointment, select the **Change intervention status** icon, and choose the action, for example **Confirm**. See [Manage an appointment from the schedule](../planning/manage-an-appointment-from-the-schedule.md) and [Understand appointment statuses](appointment-statuses.md).
8. **Find your appointments.** Go to **Planning > Appointments menu > Search for appointments**, enter your criteria, then act on a selection. See [Search for appointments](../appointments/search-for-appointments.md).
9. **Declare an unavailability.** Go to **Planning > Planning menu > Manage unavailabilities**. See [Create an unavailability](../unavailabilities/create-an-unavailability.md).
10. **Monitor the activity.** Open **Supervision** to track the appointments, read the log and view dashboards. See [Supervision overview](../supervision/supervision-overview.md).

## If something does not go as planned

| Situation | What to do |
| --------- | ---------- |
| No slot suits the appointment | In **Other actions**, you can set the status to **Suspended** or **Requested**, subcontract the appointment, or use **Manual scheduling**. See [Schedule an appointment](../appointments/schedule-an-appointment.md) and [Schedule an appointment manually](../appointments/schedule-an-appointment-manually.md). |
| A message appears about a constraint | Read the messages at the top of the screen before you use **Force appointment**. See [Schedule an appointment manually](../appointments/schedule-an-appointment-manually.md). |
| A module or a menu is missing | The modules and the actions depend on your profile. Ask your administrator. See [Manage profiles and permissions](../administration/manage-profiles-and-permissions.md). |
| You need a quick answer | [FAQ overview](../faq/faq-overview.md) |
| You do not know a term | [Glossary](../reference/glossary.md) |

## Tips

{% hint style="info" %}
**Use the shortcuts**: The Planning screen has the shortcuts **BOOK A NEW APPOINTMENT**, **SEARCH FOR APPOINTMENTS** and **SEARCH FOR CUSTOMERS**. See [Planning overview](../planning/planning-overview.md).
{% endhint %}

{% hint style="info" %}
**Customers first**: An appointment is created from a customer record, so the customer must already exist. See [Customers overview](../customers/customers-overview.md).
{% endhint %}
